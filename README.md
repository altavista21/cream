# myUI

A responsive, editorial-style UI showcase inspired by the supplied 3×3 professional-cards reference.

## Preview locally
Open `index.html` in a browser. The page is static and does not require a build step.

## Design
- Warm beige canvas with a terracotta accent
- Nine profession cards with pastel icon circles
- Playfair Display headings and DM Sans body copy
- Lucide outline icons
- Responsive layout: three columns on desktop, two on medium screens, one on small phones

Fonts and icons are loaded from public CDNs, so an internet connection is needed for those assets.
